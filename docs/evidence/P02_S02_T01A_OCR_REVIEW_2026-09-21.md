## 1. Execution layer

The repository designated Alibaba OCR as its AI review engine in P00, but the hosted semantic
layer needs a scoped LLM endpoint that does not exist in this environment. OCR ships a first-class
execution mode for exactly that situation: **delegation mode**. OCR performs the deterministic
engineering (file selection, exclusion reasons, rule resolution) and the host agent performs the
semantic review with its own model, under OCR's own accounting and rule set. The hosted layer is
never claimed.
