### 2.2 Workspace packages

Only two packages exist, because only two are earned at P00.

`@ineractive/protocol` is a boundary placeholder with **no** runtime API. Provider-neutral identity
and revision primitives, run/event/evidence/finding schemas, ModelTask, DecisionTask, and
CapabilityRequest/Grant contracts are owned by IN-P01-S02-T01 and IN-P01-S02-T02. Inventing them here
would create unreviewed public API. Two tests enforce the placeholder: the module exports nothing, and
the manifest declares no dependency.

## 4. Scope incident (recorded, not hidden)

The first `npx pnpm@12.4.2 run format` rewrote 13 canonical planning documents under
`docs/canonical/` plus `specs/tasks.md`. That is unreviewed mutation of canonical planning authority.
The change was reverted (`git checkout -- docs specs`) and `**/*.md` was added to `.prettierignore`
before any further gate ran. ADR-0001 §5.2 records the decision and its tradeoff.
