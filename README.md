# Ineractive

**From intent to product.**

Ineractive is an AI product-building platform being designed to turn a product idea into a real, inspectable, testable, deployable application: interface, data model, authentication, storage, workflows, tests, security controls, and deployment.

> **Status:** foundation planning. No working product is claimed yet.

## Canonical product name

The product name is **Ineractive**. The current GitHub repository locator is `TheHalfMoon/Inercative`; the spelling mismatch is not product authority and may be corrected separately.

## Planning principles

- The harness matters more than any single model.
- Models propose; typed system contracts, tools, tests, policy, and evidence decide.
- Ask users only questions that materially change a hard-to-reverse product decision.
- Generated applications use real code and remain exportable.
- Supabase is the first-class backend target for the first product generation.
- Build and verify in isolated runtimes before publishing.
- SpecGrain controls decomposition and execution readiness.
- Diffcipline controls proof-before-done.
- Alibaba Open Code Review is the designated AI review engine, not the acceptance authority.
- Exact repository truth and executed evidence outrank agent self-report.

The canonical planning package will live under `docs/canonical/` and `specs/`.
